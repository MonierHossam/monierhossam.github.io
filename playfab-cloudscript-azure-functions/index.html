    FAQ

    Questions studios ask

    Should I use CloudScript or Azure Functions?

    Legacy CloudScript is quick for small, self contained logic. Azure Functions suit anything that needs external APIs, more compute or full C#. I will look at what your game needs and recommend the simplest option that holds up.

    Can server code fix a feature that does not work in WebGL?

    Often yes. For Invision I moved Twitter login, which could not run in the WebGL client, into an Azure function called through PlayFab CloudScript, and it worked in the browser build.

    Will this stop players from cheating?

    Server side validation removes the easiest cheats, because the client can no longer decide rewards or results on its own. I will tell you honestly which risks remain.

    Do you also build the Unity side?

    Yes. I am a Unity developer first, so the client calls, UI and error states are covered too.
