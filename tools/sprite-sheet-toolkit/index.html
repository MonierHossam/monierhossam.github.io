Sprite Sheet Toolkit

A free, browser-based toolkit for game artists. Slice sprite sheets, auto-remove backgrounds, detect UI icons, and edit images with a built-in Photoshop-style editor.

🔒 100% private. Everything runs locally in your browser — your images are never uploaded and nothing is tracked.

The four tabs

  • Slice Sheet — grid / auto-detect / manual slicing, organize into folders, export a ZIP.
  • Remove Background — one-click cut out the background to transparent, with brush touch-up.
  • Detect Icons — auto-find UI elements and export each as a transparent PNG + layout.json.
  • Photo Edit — 20 tools: auto-BG-remove, magic eraser, crop, brush, clone, heal, filters, versions/layers, and more.

Photo Edit shortcuts

Ctrl+Z — Undo
Ctrl+Shift+Z / Ctrl+Y — Redo
Ctrl+S — Save (override)
Ctrl+Shift+S — Save As
Ctrl++ / - — Zoom in / out
Mouse wheel — Zoom at cursor
Ctrl+0 — Fit · Ctrl+1 — 100%
Enter / Esc — Apply / cancel crop

Browser support

Works in all modern browsers. Chrome & Edge additionally unlock folder browsing and save-in-place. Firefox/Safari can open, edit and download. Desktop only — touch editing isn't supported yet.
