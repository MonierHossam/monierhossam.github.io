    FAQ

    Questions studios ask

    Can PlayFab work in a Unity WebGL game?

    Yes. Many of my PlayFab projects are Unity WebGL games with email login, analytics and leaderboards running in the browser, plus server side workarounds where the browser blocks a client side call.

    Should my game use PlayFab or Firebase?

    Both are solid. PlayFab is built for games and gives you economy, leaderboards and LiveOps tools out of the box. Firebase is great for analytics, remote config and simpler data needs. I have shipped both and can help you choose before you commit.

    Can you help with a game that already uses PlayFab?

    Yes. I can join a project that already uses PlayFab to add features, fix bugs or review its CloudScript and data setup.

    Can my team use your PlayFab toolkit?

    Yes. PlayFab Hub is on the Unity Asset Store with online documentation. It covers auth, player data, economy, leaderboards and CloudScript, plus an Admin Hub inside the Editor. I can also set it up in your project as part of an engagement.

    Do you also build the Unity side?

    Yes. I am a Unity developer first, so the client integration, UI and game logic are covered too.

    How do you price this kind of work?

    Fixed scope work is quoted per milestone after a short scoping call. Ongoing work is billed monthly. Share your budget range in the form and I will tell you honestly what it can cover.
